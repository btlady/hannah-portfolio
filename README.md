# 余浣 Hannah · 个人作品集

这是可直接部署到 GitHub Pages 的静态网站。`index.html`、`styles.css`、`script.js`、`assets/` 和 `.nojekyll` 应位于仓库根目录。

## 在 Codex 中部署

将此 ZIP 上传给 Codex，并告诉它：

> 请把 ZIP 解压后的全部文件放到我的 GitHub 仓库根目录，保留 assets 文件夹和 .nojekyll。配置 GitHub Pages 从 main 分支的 /(root) 发布；不要修改网站设计或作品内容。部署后检查首页、五个作品分类、图片弹窗、两个 AIGC 视频和 PDF 简历是否可正常打开，并把仓库与网站链接给我。

如果还没有 GitHub 仓库，请先在 GitHub 新建一个仓库，再将仓库链接提供给 Codex。GitHub Pages 发布设置位于仓库 Settings → Pages，选择 Deploy from a branch → main → /(root)。

网页使用相对路径，适用于 `用户名.github.io/仓库名/` 和用户主页仓库。部署为公开 GitHub Pages 时，网站中的简历和作品素材也会公开访问。
